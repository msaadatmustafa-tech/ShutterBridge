# Changelog

## 1.5.0 — 2026-11-04

Public launch as **ShutterBridge**, an independent SayCheese alternative.

- Camera Studio UI for iPhone, Windows and browser remote.
- Native iPhone quality controls and full-screen recording view.
- Atomic camera format/FPS changes, device-reported capabilities, confirmed dimensions/FPS and saved-clip metadata.
- Preserve pending quality selections during remote status polling.
- Start/save state locks, front/back switching and zoom.
- Local Photos saving with Files originals; owner confirmed Gallery saves.
- Optional local Wi-Fi live preview, QR link and Android/laptop browser controls.
- Foreground connection recovery using the same preview session; explicit Off revokes it.
- Windows EXE and unsigned iPhone IPA; 19 automated tests and physical iPhone recording matrix documented.

## Earlier development

BLE protocol, foreground camera permissions, cloud unsigned iOS build, desktop controller, Photos saving and Wi-Fi remote were developed in earlier private iterations. Git history retains those changes.
